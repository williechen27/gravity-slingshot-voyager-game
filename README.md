# 航海家號：太陽系引力彈弓任務（3D game_3）

這是一個以「引力彈弓」為核心的 3D 太空飛行教學遊戲。玩家從地球附近出發，使用少量推進劑修正方向，依序飛掠木星、土星、天王星、海王星，最後抵達冥王星。

## 玩家要完成什麼？

玩家不是把飛船直接撞向行星，而是要：

1. 觀察行星的公轉方向與綠色目標箭頭。
2. 用推進器把飛船送到行星外圍。
3. 從行星側面安全掠過，讓行星重力改變飛船的方向與日心速度。
4. 依序完成五個航點，盡量少用推進劑抵達冥王星。

這個版本採用固定的教學路線：

**木星 → 土星 → 天王星 → 海王星 → 冥王星**

路線靈感來自 Voyager 2 的外行星大巡航；冥王星則加入 New Horizons 的任務意象，作為遊戲終點。遊戲使用壓縮過的比例與重力參數，重點是理解飛掠幾何與能量交換，而不是重現真實任務的精確軌道。

## 操作

- `W` 或 `↑`：推進，消耗有限推進劑
- `A` 或 `←`：左轉
- `D` 或 `→`：右轉
- `空白鍵`：暫停／繼續
- 滑鼠拖曳：旋轉 3D 鏡頭
- 滑鼠滾輪：縮放或旋轉鏡頭
- 滑鼠中鍵：平移鏡頭
- `手動駕駛`：完整控制飛船
- `自動朝向下一目標`：只協助轉向，仍由玩家控制推進
- `全自動展示模式`：觀察一條安全的示範飛掠路線
- `練習目前航點`：把飛船放到目前行星外圍，練習接近與掠飛

## 讀懂控制台

- **目前速度**：飛船相對遊戲太陽系的速度
- **最近距離**：本次航點接近目標時記錄的最近距離
- **日心能量**：簡化的 `v²/2 - μ/r`，數值提高通常代表更有能力前往外側航點
- **成功助推**：安全進入指定飛掠範圍的航點數
- **任務進度**：目前完成的固定航點與下一個目標

成功飛掠時，畫面會顯示該次飛掠的速度變化與累計助推次數。撞上任何行星會任務失敗，必須重新開始。

## game_3 的新增內容

- 固定且可理解的 Voyager 大巡航任務路線
- 補上冥王星、任務完成條件與完成畫面
- 任務進度清單與目前航點提示
- 飛掠成功事件提示、最近距離、日心能量與助推次數
- 高時間倍率下的固定小步長計算，降低近距離飛掠的不穩定
- 展示模式也遵守安全飛掠與碰撞規則
- 「練習目前航點」功能，方便學習單一行星的飛掠幾何
- 暫停按鈕會顯示目前狀態，第一視角與 3D 鏡頭功能保留

## 科學簡化

在行星參考系中，飛船接近與離開時的相對速度大小大致相同，但方向會被行星重力彎折。回到太陽參考系後，飛船速度向量和行星公轉速度重新相加，因此可能取得或交還軌道能量。

遊戲將太陽、行星與飛船都放在同一個簡化的二維物理平面，再用 3D 場景呈現軌道、行星與飛船。推進器是修正工具；大幅改變方向與日心能量的關鍵仍是飛掠幾何。

## 執行方式

直接開啟 `index.html` 即可。若瀏覽器支援 WebGL，會使用 3D 場景；若 WebGL 或外部 3D 資源無法載入，會自動切換到 Canvas 2D fallback，保留基本玩法。

3D 版本目前會從 CDN 載入 Three.js 與行星貼圖，因此第一次載入 3D 畫面需要網路。離線時仍可進入 2D fallback；若要完全離線的 3D 版本，下一步可把這些資源放進專案內。
