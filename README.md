# 航海家號：太陽系引力彈弓任務

這是一個以「引力彈弓（Gravity Assist / Slingshot）」為核心的太空飛行模擬與教學遊戲。玩家可以操控航海家號，在太陽系中練習推進、轉向與行星飛掠，依序前往木星、土星、天王星、海王星與冥王星。

本專案的數值與畫面是教育用途的簡化模型，不是 NASA 即時遙測，也不是精確的航天任務規劃工具。

## 版本特色

### 以 AU 比例呈現行星軌道

修改版使用各行星真實的近似軌道半長軸比例，並以 `1 AU = 60` 個場景單位呈現：

| 天體 | 軌道半徑（AU） | 相對黃道面傾角 |
| --- | ---: | ---: |
| 水星 | 0.3871 | 7.005° |
| 金星 | 0.7233 | 3.3947° |
| 地球 | 1.0000 | 0° |
| 火星 | 1.5237 | 1.8506° |
| 木星 | 5.2028 | 1.303° |
| 土星 | 9.5388 | 2.485° |
| 天王星 | 19.1914 | 0.773° |
| 海王星 | 30.0611 | 1.770° |
| 冥王星 | 39.4820 | 17.16° |

3D 畫面會依照軌道傾角與升交點方向繪製不同的軌道平面。為了讓物件在畫面上容易辨認，行星與飛船大小仍經過視覺放大，並非真實尺寸比例。

### 引力彈弓模擬

- 行星會依照各自的公轉方向移動。
- 飛船接近行星時，行星引力會改變飛船的速度與方向。
- 遙測面板會顯示速度、燃料、任務時間、最近距離與成功助推次數。
- 任務路線依序以木星、土星、天王星、海王星與冥王星為航點。

### 安全的自動展示模式

全自動展示模式會：

- 對準目前任務目標。
- 使用較大的安全飛掠半徑接近行星。
- 在接近目標時使用切線方向與逃逸速度修正。
- 同時偵測並避讓所有非目標行星，避免航線直接穿過其他天體。

手動模式仍保留正常碰撞判定，必須從行星外圍安全掠過。

## 操作方式

### 飛行控制

- `W` 或 `↑`：推進
- `A` 或 `←`：向左轉
- `D` 或 `→`：向右轉
- `空白鍵`：暫停／繼續模擬
- 「推進器啟動」：切換持續推進
- 「重新開始」：重設任務
- 「練習目前航點」：將飛船定位到目前目標附近，練習安全飛掠

### CAD 風格視角控制

- 滑鼠左鍵拖曳：旋轉 3D 視角
- 滑鼠中鍵拖曳：平移場景
- 滑鼠滾輪：縮放視野
- 觸控裝置單指拖曳：旋轉視角
- 觸控裝置雙指操作：縮放視野
- 「重設視角」：恢復預設視角並重新跟隨飛船

畫布內的右鍵選單已停用，以避免干擾視角操作。

## 飛行輔助模式

- **手動駕駛**：由玩家自行控制方向與推進。
- **自動朝向下一目標**：只協助調整船頭方向，推進仍由玩家控制。
- **全自動展示模式**：自動控制航向與推進，展示安全的重力助推流程。

## 遙測資訊

- **速度**：飛船在模擬座標中的速度大小。
- **剩餘燃料**：推進器可使用的燃料比例。
- **已耗燃料**：任務開始後的燃料消耗量。
- **任務時間**：模擬中的任務經過時間。
- **最近行星**：目前距離飛船最近的行星。
- **最近距離**：飛船與任務目標的最近接近距離。
- **日心能量**：簡化的日心軌道能量指標。
- **推進流量**：目前的推進燃料消耗狀態。
- **成功助推**：已完成的安全行星飛掠次數。

## 專案檔案

- `index.html`：原始版本，作為基準檔案保存。
- `indexv2.html`：加入現實軌道比例、軌道傾角、自動避障與 CAD 滑鼠控制的修改版。
- `agent.md`：後續代理或開發者應遵循的修改規範。

## 技術說明

- 使用 HTML、CSS 與原生 JavaScript。
- 3D 畫面使用 Three.js。
- 瀏覽器不支援 WebGL 時，會切換到 Canvas 2D 後備畫面。
- 行星材質透過公開 GitHub 鏡像載入；離線或網路受限時，材質可能無法顯示，但模擬邏輯仍可運作。
- 2D 物理計算與 3D 軌道顯示採用投影對應，因此是教學用近似模型，不代表完整的 N-body 或高精度克卜勒軌道解算。
