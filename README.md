## 🎮 操控方式

- `🚀 發射按鈕`：停泊地球時點擊自地球起飛，升空後切換為「🔥 推進」點火加速
- `滑鼠右鍵拖曳拉線`：簡潔微光虛線即時控制船頭朝向與推進燃燒力度（0%~100% 直觀推力）
- `<kbd>W</kbd>` 或 `<kbd>↑</kbd>`：點火推進（發射階段具備 32.0 單位/s² 火箭推力，巡航機動為 8.5 單位/s²）
- `<kbd>A</kbd>` 或 `<kbd>←</kbd>`：向左轉向
- `<kbd>D</kbd>` 或 `<kbd>→</kbd>`：向右轉向
- `<kbd>空白鍵</kbd>`：暫停／繼續模擬
- `<kbd>滾輪</kbd>` 或 `縮放滑桿`：調整視野高低（縮放範圍 **0.005× 至 200.0×**，支援暫停時調整）
- `滑鼠左鍵拖曳`：自由平移探索太陽系星圖（精確 1:1 抓地平移）
- `雙擊畫布` 或 `居中鎖定按鈕`：將視野焦點重新鎖定於推進器小球
- `<kbd>ESC</kbd>`：關閉飛行手冊彈窗
- `飛行輔助選單`：
  - **手動駕駛**：完整手動自主飛行控制
  - **自動朝向下一目標**：自動對準目標航點方位
  - **全自動展示模式**：示範安全引力助推最佳航線與極致省油巡航
- `練習目前航點`：快速重置並定位至當前目標行星外圍進行掠飛練習

## 🛰️ 讀懂遙測控制台 (Telemetry)

- **航速**：飛船相對日心座標系的速度大小。
- **剩餘推進劑**：初始 100%，耗盡後僅能依靠重力慣性飛行。
- **預計最近距**：未來軌道預測線與目標行星的最接近距離與安全判定。
- **日心軌道能量**：簡化數值 $v^2/2 - \mu/r$，數值越高代表越有能力向外太陽系擴展軌道。
- **最近天體 / 實際最近距**：目前距離飛船最近的行星與距離記錄。
- **助推次數**：成功安全完成重力助推的次數。
- **任務耗時**：自啟航以來的太陽系時間（以年為單位）。
