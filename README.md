# 航海家號：太陽系引力彈弓任務

**Voyager Mission Control（太陽系引力助推巡航模擬）**是一款以繁體中文呈現的互動太空飛行教育遊戲。玩家從地球附近出發，操控探測船依序飛掠木星、土星、天王星、海王星與冥王星，觀察太陽與行星的引力如何改變飛船的速度和航向。

本作品是為學習與遊玩設計的簡化模擬，不是 NASA 任務軟體，不提供真實航行建議或即時遙測資料。

## 專案目標

- 用可操作的方式介紹行星公轉、重力與引力彈弓。
- 讓玩家比較手動操控、目標航向輔助與全自動展示模式。
- 透過燃料、航點、軌跡和遙測讀值，觀察不同操作對飛行結果的影響。

## 主要功能

- **太空場景：**使用 Three.js 與 WebGL 顯示太陽、行星、飛船、軌道及飛行軌跡。若 Three.js 或 WebGL 無法使用，會改用 Canvas 2D 後備畫面。
- **行星與軌道：**軌道半徑依近似 AU 比例設定，場景中以 1 AU 約等於 60 個模擬單位；行星傾角也以近似值呈現。軌道、速度、質量及重力仍經過簡化，並非精確星曆或高精度天體力學模型。
- **任務航點：**依序飛掠木星、土星、天王星、海王星及冥王星。達到遊戲設定的安全飛掠條件後，任務會更新航點、進度與飛行紀錄。
- **推進與燃料：**推進力滑桿範圍為 0.2×–2.0×。手動推進力和燃料消耗會依倍率連動；玩家可按住推進或啟動推進器。
- **飛行輔助：**提供手動駕駛、自動朝向目標及全自動展示三種模式，詳見下方說明。
- **遙測與紀錄：**顯示速度、燃料、耗用燃料、電力、任務時間、目前目標、最近距離、日心能量、推進流量及成功助推數，並記錄操作、事件與警告。
- **鏡頭操作：**WebGL 模式可用左鍵拖曳旋轉、右鍵拖曳平移，並可使用滾輪或滑桿縮放；縮放範圍為 0.45×–10.0×。觸控裝置支援單指拖曳與雙指縮放。按「重設視角」會回到預設第三人稱跟隨鏡頭。
- **第一人稱與航點練習：**可以切換第一／第三人稱，或將飛船移至目前航點附近練習安全飛掠。
- **行動裝置版面：**較窄螢幕會調整控制台排列。Canvas 2D 後備模式可拖曳平移場景，但不提供真正的 3D 旋轉。
- **科普內容：**頁面下方提供引力彈弓介紹、公式、任務案例與延伸閱讀。

## 操作方式

| 操作 | 控制方式 |
| --- | --- |
| 推進 | 按住 `W` 或 `↑`，或按住畫面上的推進按鈕 |
| 持續推進 | 按「推進器啟動」；再按一次停止 |
| 左轉／右轉 | `A`／`D` 或 `←`／`→`，也可按住畫面方向按鈕 |
| 調整推進力 | 推進力滑桿，0.2×–2.0× |
| 暫停／繼續 | 空白鍵或「暫停」按鈕 |
| 調整模擬速度 | 時間倍率滑桿，0.3×–5.0× |
| WebGL 3D 視角旋轉 | 在場景上按住滑鼠左鍵拖曳；觸控裝置可單指拖曳 |
| WebGL 3D 視角平移 | 在場景上按住滑鼠右鍵拖曳 |
| Canvas 2D 後備畫面平移 | 在場景上拖曳 |
| 縮放場景 | 滑鼠滾輪、鏡頭縮放滑桿；觸控裝置可雙指縮放。範圍 0.45×–10.0× |
| 恢復預設鏡頭 | 按「重設視角」 |
| 練習目前航點 | 按「練習目前航點」 |
| 切換視角 | 按「切換為第一視角」或「切換為第三視角」 |

滑鼠鏡頭操作只改變觀察視角，不會直接操控推進器。若右鍵拖曳時仍出現瀏覽器選單，請確認游標位於中央場景上。

## 飛行輔助模式

- **手動駕駛（`none`）：**玩家控制轉向和推進。推進力倍率會影響推力與燃料消耗。
- **自動朝向下一目標（`target`）：**程式依目前航點、飛船與行星的相對速度估算短時間後的目標位置，再平滑調整船頭。預判時間有上限；資料不可靠時會退回瞄準行星目前位置。此模式只負責轉向，推進仍須由玩家操作，不會自動消耗燃料。導航診斷資料會輸出至瀏覽器主控台。
- **全自動展示（`demo`）：**程式會自行轉向並進行示範燃燒，會消耗燃料。它用於展示簡化的飛掠流程，不是實際飛行規劃器，也不保證安全或最佳化的真實軌跡。

## 技術架構

- 單頁靜態網站，使用 HTML、CSS 與原生 JavaScript；遊戲介面、模擬及渲染程式集中在 `index.html`。
- Three.js r128 由 cdnjs CDN 載入，以 WebGL 繪製 3D 場景；失敗時使用 Canvas 2D 後備渲染。
- 使用瀏覽器的 `requestAnimationFrame` 更新模擬與畫面，並以 Pointer Events 處理滑鼠及觸控鏡頭操作。
- 專案沒有 `package.json`、npm 套件、建置流程或內建自動化測試套件。

## 本機啟動

需求：Python 3（只用來提供靜態網頁）及支援 Canvas 的現代瀏覽器。建議使用可啟用 WebGL 的瀏覽器。遊戲不需要安裝 npm 套件。

在專案根目錄執行：

```powershell
py -m http.server 8000
```

接著開啟 <http://localhost:8000/>。也可以直接用瀏覽器開啟 `index.html`；使用本機伺服器通常較方便檢查與預覽。

3D 場景需要瀏覽器連線至 Three.js CDN；行星材質與內嵌 YouTube 教學影片也需要網路。若 Three.js 或 WebGL 無法載入，遊戲會嘗試切換至 Canvas 2D 後備畫面；離線時遠端材質與影片不會顯示。

## GitHub Pages 部署

本專案是靜態網站，不需要建置。將 `index.html` 和 `README.md` 放在發布來源根目錄，或放入 GitHub Pages 設定使用的 `docs/` 目錄，然後在儲存庫的 **Settings → Pages** 選擇對應來源即可。

部署後，Three.js CDN、遠端材質及 YouTube 仍需可連線。由於此工作目錄沒有 Git 遠端設定，實際儲存庫的 Pages 分支與目錄設定無法在此確認。

## 測試與驗收

目前沒有專案自帶的測試框架。本次文件更新前，已對 `index.html` 內嵌 JavaScript 執行 Node.js 語法檢查，結果通過；也已核對推進力倍率、縮放上限及左鍵旋轉／右鍵平移的程式碼。這些檢查不等同於在瀏覽器中完整操作遊戲。

建議發布前手動確認：

1. 場景能正常顯示；若 WebGL 不可用，確認 Canvas 2D 後備畫面可啟動。
2. 用鍵盤與畫面按鈕轉向、推進，並確認燃料會隨推進消耗。
3. 將推進力調至 0.2× 與 2.0×，確認讀值更新，且較高倍率在相同操作時間下消耗較多燃料。
4. 切換 `target` 模式，確認飛船只轉向；沒有玩家推進輸入時，不會自行啟動推進器或扣除推進燃料。
5. 測試 `demo` 模式、航點練習、飛掠成功、撞擊失敗、暫停與重新開始。
6. 在 WebGL 模式確認左鍵旋轉、右鍵平移、滾輪縮放可到 10.0×，且右鍵不會開啟瀏覽器選單；按「重設視角」確認鏡頭恢復跟隨。
7. 在窄螢幕檢查面板排列、操作按鈕與頁面捲動。

## 已知限制

- 這是教育遊戲尺度，不是高精度軌道力學：行星大小、相位、速度、質量、引力係數、推進力、燃料與時間均有簡化。雖然軌道半徑按 AU 比例設定，並使用傾角近似值，仍不可將模擬結果當成真實任務數據。
- 遊戲中的電力會依模擬時間及推進狀態下降並顯示警告，但不會限制推進或改變飛行物理。
- `target` 航向輔助不會自行推進；`demo` 展示模式會自行燃燒並耗用燃料。
- WebGL 3D 視角操作需要 Three.js 和 WebGL；Canvas 2D 後備畫面只提供平移，不提供真正的 3D 旋轉。
- 外部 CDN、材質鏡像或 YouTube 服務中斷時，對應內容可能無法載入。
